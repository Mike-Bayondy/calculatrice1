🧮 CalculatriceApp

Une petite application de calculatrice en Java (Swing) développée avec NetBeans.
Elle permet d’effectuer les opérations de base : addition, soustraction, multiplication et division.

📂 Structure du projet

Le projet est organisé en 3 classes principales pour séparer les responsabilités :

Calculatrice → contient la logique des calculs.

CalculatriceUI → gère l’interface graphique et les interactions avec l’utilisateur.

MainApp → point d’entrée de l’application (méthode main).

🚀 Fonctionnalités

Interface graphique simple avec Swing.

Opérations : +, -, *, /.

Gestion des nombres décimaux.

Affichage clair (supprime les .0 inutiles).

Gestion des erreurs (ex : division par zéro).

▶️ Lancer le projet

Ouvre NetBeans.

Crée un nouveau projet Java Application (sans main déjà généré).

Ajoute les fichiers suivants dans le package calculatriceapp :

Calculatrice.java

CalculatriceUI.java

MainApp.java

Clique droit sur MainApp.java → Run File.
